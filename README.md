# 🌐 Mini Portfolio

A minimal, responsive, and animated portfolio website built with **React**, **TailwindCSS**, and **EmailJS**, designed to showcase your profile, projects, and contact options. Deployed on **Vercel**.
This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## ✨ Features

- 🚀 Smooth scroll-based navigation
- 🎨 Gradient animations and modern UI design
- 📱 Fully responsive (mobile-first)
- 💌 Contact form integration via EmailJS
- 🌙 Dark mode toggle
- ⚡ Fast build with `pnpm`

## 📦 Tech Stack

- **React** — Frontend framework
- **TailwindCSS** — Utility-first styling
- **EmailJS** — Contact form without backend
- **Vercel** — Hosting & deployment
- **PNPM** — Package management
